# Brand System

## 1. Purpose

Defines the visual identity of **Esther Manrique González, Frontend Software Engineer**. A recognizable, consistent, timeless professional identity that extends across the portfolio, GitHub, LinkedIn, resume, and future work.

## 2. Brand Architecture

- **Primary identity**: Esther Manrique González — used for portfolio, resume, LinkedIn, recruiter communication.
- **Professional title**: Frontend Software Engineer — consistent across all platforms.
- **Secondary signature**: Manrique — personal side projects, experimental work, footer signature.

## 3. Logo System

- **Primary**: monogram + name + professional title (hero, resume).
- **Horizontal**: monogram + name (navigation, header).
- **Monogram**: the "M" symbol (favicon, social profile, avatar).

## 4. Visual Language

Editorial sophistication combined with engineering precision. Graphic elements: circular frame, monogram, pixel fragments, circuit-inspired details, fine dividers, editorial spacing — each with a clear purpose.

## 5. Typography Philosophy

- **Editorial voice**: elegant, expressive — headlines, hero, key statements.
- **Technical voice**: clean, modern, highly readable — body, navigation, interface.

## 6. Color Philosophy

Premium, timeless, recognizable. Communicates confidence, warmth, professionalism, creativity, precision. Concrete values in `design-system/design-tokens.md`.

## 7. Motion Identity

Motion reinforces quality, never attracts attention: smooth, deliberate, elegant, lightweight.

## 8. Brand Personality

Elegant, intelligent, technical, human, thoughtful — never loud, trend-driven, corporate, or generic.

## 9. Brand North Star

> Does this reinforce the identity of Esther Manrique González as a Frontend Software Engineer who combines engineering excellence with thoughtful design?
